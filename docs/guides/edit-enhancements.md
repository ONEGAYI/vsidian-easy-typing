# 编辑增强使用指南

Vsidian Easy Typing 提供多种智能编辑功能，在输入时自动生效。这些功能旨在减少按键次数、提升编辑流畅度，尤其适合使用中日韩文字写作的用户。本指南移植自上游 [easy-typing-obsidian](https://github.com/Yaozhuwa/easy-typing-obsidian) 的 EditEnhancements 文档，并按本平台已实施形状改写。

> 本页介绍的是**编辑行为增强**（快捷键、光标跳转、粘贴等）。如果你在找自动配对、全角半角标点转换、符号快捷输入等功能，请参阅[自定义规则指南 → 内置规则](custom-rules.md#内置规则速览)；中英文自动空格见[自动格式化指南](auto-formatting.md)。

## Tab 跳出配对符号

按 **Tab** 键将光标跳出配对符号。当光标在配对符号内部时，按 Tab 会把光标移到闭合符号之外：光标紧贴闭合符时一步跳出；与闭合符之间有内容时，第一次 Tab 先跳到闭合符之前，再按一次跳出（两步）。选中文本两侧紧贴同一对配对符时同样可跳出。

支持的 22 对符号：

| 分类 | 符号 |
|------|------|
| 中日韩符号对 | `【】`、`（）`、`《》`、`""`、`''`、`「」`、`『』` |
| 标准符号对 | `()`、`[]`、`{}`、`<>`、`''`、`""` |
| Markdown 符号对 | `$$`、`$`、`**`、`*`、`__`、`_`、`==`、`~~`、`[[]]` |

> 未命中时 Tab 原样透传给编辑器（缩进、Tab 导航等平台行为不受影响）。

## 智能退格键

增强退格键对列表与引用结构的处理：

| 场景 | 效果 |
|------|------|
| 空列表项（如 `- `、`1. `） | 按退格移除列表标记 |
| 有序列表项退格 | 后续同级列表项**自动重新编号**（含跳号截断等形态） |
| 空引用行（如 `> `） | 四分支：多级引用联动降级、单级降级、与上一行合并、清除整行前缀（多级降级保留前导缩进） |

> 嵌套空列表项、空任务项（`- [ ] `）与引用内列表三处形态**有意让位**给编辑器平台内建行为处理（如空任务项退格时，平台把任务标记与列表标记作为一个单元整段清除）。

## 增强 Mod+A

渐进式选择扩展（`Ctrl/Cmd+A`）：

| 按下次数 | 效果 |
|---------|------|
| 第 1 次 | 选中当前行 |
| 第 2 次 | 选中当前文本块 |
| 第 3 次 | 选中全文（平台原生全选补完） |

> 此功能默认**关闭**，需在设置（「增强 Ctrl/Cmd+A 功能」）中手动启用。关闭时 Mod+A 完全走平台原生全选。

另有恒可用的**「选择当前文本块」命令**（进命令面板与统一快捷键管理，默认未绑定键位）——不依赖上面的开关。

## 智能粘贴

在列表或引用块中粘贴文本时，插件自动为每一行添加对应的前缀：

| 上下文 | 自动处理 |
|--------|---------|
| 在列表中 | 每行粘贴内容获得列表缩进与标记延续 |
| 在引用块中 | 每行粘贴内容获得 `> ` 前缀 |

配套的**「纯文本粘贴（跳过自动格式化）」命令**：默认键位 `Ctrl+Shift+V`（macOS `Cmd+Shift+V`）——粘贴原始文本并跳过自动格式化，等价于平台无格式粘贴且额外置跳过标记。

> Windows/Linux 下 `Ctrl+Shift+V` 与平台内建「粘贴纯文本」同弦：默认状态平台命令先命中（粘贴内容等价，不置跳过标记）；需要确保跳过格式化的场景可改绑本命令或用命令面板入口。

## 当前行下方新建行

`Ctrl/Cmd+Enter` 在当前行下方新建一行并移入光标：

- 列表/引用上下文自动延续前缀（有序列表自动递增编号、任务项重置为未完成）；
- 普通文本行仅插入空行；
- 关闭「Ctrl/Cmd+Enter 在下方新建行」设置后回退编辑器内建行为（仅插入空行，光标不动）。

> 上游的**严格换行（strict line breaks）回车增强**暂未实施——该功能依赖 Obsidian 特有的严格换行渲染语义，在 Vsidian 平台的对应形态待产品决策（决策记录 [ADR-0002](../adr/0002-strict-line-break-mapping.md)）。

## 折叠标题回车

在折叠的标题行按回车时，不展开折叠内容，直接在下方添加同级标题行。方便快速搭建文档大纲。默认开启，可在设置（「折叠标题回车不展开」）中关闭。

## 注释切换

`Ctrl/Cmd+/` 切换行注释：

- **代码块内**：按围栏语言选用注释符（Python 的 `#`、JS 的 `//` 等，覆盖上游 26 种语言注释符表）；块注释语言（如 C）整块切换；
- **Markdown 正文**：切换 `%%` Obsidian 内联注释。

> Windows/Linux 下 `Ctrl+/` 与平台内建 HTML 注释（`<!-- -->`）同弦：默认状态平台命令先命中（HTML 注释语义照常执行）；macOS 的 `Cmd+/` 归本命令。改绑任一侧（平台快捷键管理）后相应入口归本命令；命令面板入口恒可用。

## 命令与键位参考

| 命令 / 键位 | 入口 | 说明 |
|------|--------|------|
| 当前行下方新建行 | `Ctrl/Cmd+Enter` | 键位拦截（设置门控）；关闭时回退平台内建行为 |
| 注释切换 | `Ctrl/Cmd+/` | 命令 + 默认热键（Windows/Linux 与平台 HTML 注释同弦，见上文） |
| 纯文本粘贴（跳过自动格式化） | `Ctrl/Cmd+Shift+V` | 命令 + 默认热键（与平台无格式粘贴同弦，见上文） |
| 选择当前文本块 | 默认未绑定 | 命令面板 / 统一快捷键管理 |
| Tab 跳出配对符 | `Tab` | 键位拦截，未命中透传 |
| 智能退格 | `Backspace` | 键位拦截，未命中透传 |
| 增强 Mod+A | `Ctrl/Cmd+A` | 设置门控（默认关） |

> 上游的「格式化全文 / 格式化选区 / 切换自动格式化」命令族随 [#28](https://github.com/ONEGAYI/vsidian-easy-typing/issues/28) 落地。
