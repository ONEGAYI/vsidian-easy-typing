# 文本自动格式化使用指南

Vsidian Easy Typing 在输入时自动格式化文本：在不同文字类型和行内元素之间添加适当的空格，自动大写句首字母，并保护特殊文本模式不被破坏。本指南移植自上游 [easy-typing-obsidian](https://github.com/Yaozhuwa/easy-typing-obsidian) 的 AutoFormatting 文档，并按本平台已实施形状改写。

## 开箱即用

安装并启用后，以下自动格式化功能默认生效：

| 功能 | 默认行为 |
|------|---------|
| 中英文之间加空格 | 启用 |
| 中文与数字之间加空格 | 启用 |
| 数字与英文之间加空格 | 启用 |
| 句首字母大写 | 未启用 |
| 行内代码间距 | 软空格 |
| 行内公式间距 | 软空格 |
| 链接间距 | 软空格 |
| 自定义正则保护区 | 启用（出厂模板） |

> 所有自动格式化操作都可以用 `Ctrl/Cmd+Z` 撤销。注意本平台的撤销粒度：**规则修饰与键入本身分属两个撤销步**——一次撤销回退格式化插入的空格，再按一次撤销回退刚才输入的字符。

如需调整，打开 Vsidian 设置 → 附加组件 → Easy Typing 的设置项。

## 中英文之间自动加空格

这是最常用的功能。输入时，插件会自动在不同文字类别的相邻字符之间插入空格。

**效果示例**：

| 输入 | 格式化结果 |
|------|-----------|
| `你好world` | `你好 world` |
| `使用Python3编程` | `使用 Python3 编程` |
| `共100个` | `共 100 个` |

### 支持的文字类别

| 类别 | 字符范围 |
|------|---------|
| 中文 | CJK 统一汉字及扩展 A (U+4E00–U+9FFF, U+3400–U+4DBF) |
| 日文 | 平假名 (U+3040–U+309F)、片假名 (U+30A0–U+30FF, U+31F0–U+31FF) |
| 韩文 | 韩文音节 (U+AC00–U+D7AF)、韩文字母 (U+1100–U+11FF, U+3130–U+318F) |
| 英文 | A-Z, a-z |
| 数字 | 0-9 |
| 俄文 | 西里尔字母 (U+0400–U+04FF) |
| CJK | 元类别：中文 + 日文 + 韩文 |

### 语言对配置

默认启用的语言对与上游一致：中文 ↔ 英文、中文 ↔ 数字、数字 ↔ 英文。

> **本仓边界**：上游设置界面里可自由增删语言对与自定义文字类别（如希腊文）；本仓当前以出厂默认三对固定生效，对应配置界面尚未开放（语言对与自定义类别的运行时消费面已就绪，开放编辑 UI 属后续工单）。

## 句首自动大写

自动将英文句首字母大写（默认关闭）。大写在输入时触发——如果结果不符合预期，可以立即撤销。

## 行内元素间距

插件将每一行分割为不同片段：**文本**、**行内代码**、**行内公式**、**链接**和**用户自定义正则区块**。对于每种行内元素，可以配置间距策略：

| 策略 | 行为 | 示例 |
|------|------|------|
| **无间距**（none） | 无间距要求 | `` 文字`code` `` |
| **软空格**（soft） | 标点符号或显式空格都可以作为分隔符 | `` 文字，`code` `` 或 `` 文字 `code` `` |
| **严格空格**（strict） | 必须有真正的空格字符 | `` 文字 `code` `` |

默认设置：

- 行内代码：软空格
- 行内公式：软空格
- 链接：软空格；「链接智能空格」开启时把 `[[双链]]` 与 `[Markdown 链接](...)` 作为整体词元参与判定（识别链接别名），关闭时完全按三档策略处理

## 进阶配置

### 前缀词典

逐字输入单词时，插件可能会过早插入空格——例如，在你要输入 `n8n` 时，输入 `n` 后就插入了空格。前缀词典通过抑制已知前缀的空格插入来避免这个问题。

条目之间可以用逗号、空格或换行符分隔。支持两种格式：

| 格式 | 语法 | 说明 | 示例 |
|------|------|------|------|
| 字面词 | 直接输入 | 支持前缀匹配，输入过程中的每个前缀都不会触发空格 | `n8n` → 输入 `n`、`n8`、`n8n` 时都不加空格 |
| 正则模式 | `/.../` 包裹 | **不支持**前缀匹配，只在完整匹配时抑制空格 | `/[23][dD]/` → 匹配 `2d`、`3D` 等 |

越过词条继续输入后，边界处此前被抑制的空格会**延迟补插**（上游同语义）。

### 软空格符号

你可以配置额外的软空格分隔符号。常见全角标点默认左右都内置支持，英文引号（' \"）默认左右都内置支持，左括号（`[` `(` `{`）默认内置为左软空格，右括号（`]` `)` `}`）和英文半角标点（`. , ? ! : ;`）默认内置为右软空格。左侧和右侧的额外软空格符号分别在「自定义左侧/右侧软空格额外符号」设置中配置。

### 用户自定义正则表达式区块

你可以用正则表达式定义特殊文本模式。匹配这些模式的文本被视为**原子块**——不会被自动格式化拆分，并且你可以指定它的间距行为。

#### 语法

正则区块配置中每行的格式：

```
<正则表达式>|<左侧策略><右侧策略>
```

间距策略符号：

- `-`：无间距要求
- `+`：严格空格
- `=`：软空格（不常用，通常选 `-` 或 `+`）

以 `//` 开头的行视为注释。

#### 默认正则区块

出厂模板包含以下默认区块：

| 模式 | 策略 | 用途 |
|------|------|------|
| `{{.*?}}` | `++` | Templater / Dataview 表达式 |
| `<.*?>` | `--` | HTML 标签 |
| `\[\!.*?\][-+]{0,1}` | `-+` | Callout 头部 |
| URL 类模式 | `--` | 链接 |
| `[a-zA-Z0-9_\-.]+@[a-zA-Z0-9_\-.]+` | `++` | 电子邮箱 |
| `#[\u4e00-\u9fa5\w-/]+` | `++` | 标签（以注释行形态随模板分发，去掉行首 `//` 即启用） |

配置入口：「自定义正则表达式开关」（总门，默认开）与「自定义正则表达式」（模板文本）。另有「自定义正则区块同时阻止用户规则」开关（默认关）：开启后，命中保护区的文本也不会触发输入规则（见[自定义规则指南](custom-rules.md)）。

> 保护区逐行独立、取非贪婪最短闭合；行尾无 `|xy` 旗标的行与非法正则行跳过（不报错）。区块与行内代码/公式天然保护区重叠时，天然保护区优先。

## 默认不会格式化的区域

自动格式化不会应用于：

- 代码块（` ``` ` 或 `~~~` 围栏）
- 数学公式块（`$$...$$`）
- Frontmatter（`---` 之间的 YAML）
- 表格格区与 IME 组合输入的中间态（平台先行排除）

此外，**输入规则命中时本次输入不格式化**——规则链与格式化链共用同一独占次序（上游同语义：`triggerCvtRule` 命中即短路格式化）。例如键入 `。。` 被标点折叠规则转换为 `.` 的那次输入，不会再叠加空格格式化。

## 命令、粘贴与撤销

| 操作 | 说明 |
|------|------|
| `Ctrl/Cmd+Z` | 撤销格式化（先撤规则修饰，再撤键入——两步，见上文） |
| `Ctrl/Cmd+Shift+V` | 纯文本粘贴：粘贴原始文本并跳过自动格式化 |
| 格式化全文 / 格式化选区 | 命令族随命令工单（[#28](https://github.com/ONEGAYI/vsidian-easy-typing/issues/28)）落地——上游的 `Mod+Shift+S` / `Mod+Shift+L` / `Ctrl+Tab` 快捷键暂未移植 |

> **粘贴格式化的边界**：上游「粘贴时自动格式化」（AutoFormatPaste）在本平台经行为链**结构性不可达**——平台对粘贴事务不驱动输入行为链。当前粘贴路径中保证不误格式化（粘贴内容带标记跳过）；「粘贴并格式化」待 #28 命令族以主动命令形态提供。

---

## 文件排除

「排除文件夹/文件」设置中列出路径（每项一条，如 `DailyNote/`、`DailyNote/test.md`）。文件路径包含任一列出的字符串时，该文件不受本插件影响（规则与格式化均不生效）。

## 与上游 Obsidian 版的差异

| 面 | 上游（Obsidian） | 本仓（Vsidian 附加组件） |
|----|------------------|--------------------------|
| 设置入口 | 插件自身设置页（5 Tab） | Vsidian 设置页 → 附加组件 |
| 语言对 / 自定义类别编辑 | 设置界面自由增删 | 出厂默认三对固定生效，编辑 UI 未开放（见上文） |
| 粘贴时格式化 | AutoFormatPaste 开关生效 | 行为链不可达；以「纯文本粘贴跳过格式化」+ 后续格式化命令（#28）替代 |
| 多光标 | 单选区处理（asSingle） | **多光标键入不格式化**（保守收窄，光标不坍缩） |
| 行类型判定 | 语法树精确判定 | 文本正则降级版（已知近似：行内公式 `$x$` 内光标会跳过整行格式化、货币 `$100` 同源误判；块级跳过由平台门控与降级判定双重保证） |
| IME 输入 | compose 感知 | 中文输入法**定稿**正常触发格式化；组合中间态（候选期）不触发、不误格式化 |
| 命令 | 格式化全文/选区、切换格式化快捷键 | 命令族随 #28 落地 |
